# ხელშეკრულებების რუკა

ხელშეკრულებებით გადაცემული ქონების ინტერაქტიული რუკა: საკადასტრო კონტურები ფერდება ხელშეკრულების სტატუსის მიხედვით,
ჩანს NAPR-ის ორთოფოტოზე ან თანამგზავრულ ფენაზე, აქვს ფილტრები, ძებნა, თარიღის მიხედვით ისტორია, ნიშნები (დავალიანება, დარღვევა…)
და საჯარო View-ები ვადით.

## როგორ მუშაობს

- **მონაცემი** Google Sheet-შია (ხელშეკრულებები, სტატუსები, ქონებების ისტორია, ნიშნები, შეზღუდვები, გეომეტრიები).
- **გვერდი** (`index.html`, `js/backend.js`) GitHub Pages-ზეა. მომხმარებელი Google-ით შედის და Sheet-ს საკუთარი უფლებით კითხულობს:
  ვისაც Sheet არ აქვს გაზიარებული, ხელშეკრულებებს ვერ ნახავს, მხოლოდ სუფთა რუკას.
- **Apps Script** (`apps-script/Code.gs`, Sheet-ზე მიბმული, საჯარო Deploy „Me“ + „Anyone“) აწვდის საჯარო View-ებს
  Google ანგარიშის გარეშე მნახველს და ამოწმებს, აქვს თუ არა შესულს რედაქტირების უფლება.

## პარამეტრები

`js/backend.js` → `CONFIG`: `clientId` (Google Cloud OAuth Client ID), `spreadsheetId`, `publicApiUrl` (Apps Script-ის საჯარო `/exec` ბმული).
კოდში საიდუმლო არ არის: Client ID საჯაროა და მხოლოდ ამ საიტიდან მუშაობს.

## პირადი რუკები (🗂 „რუკები“)

სამუშაო მაგიდის (ნაპოვნი კოდები, გეგმიდან კონტურები, ფაილები) შენახვა სახელით, სია ფილტრით (სახელი ან კოდი), გაზიარება ბმულით. კოდი: `js/personal_maps.mjs`.

- **Drive-თან დაკავშირებისას** რუკა ინახება მომხმარებლის საკუთარ Google Drive-ში, ამ საიტის დამალულ საქაღალდეში (`appDataFolder`, უფლება `drive.appdata`):
  მხოლოდ ის ხედავს, ნებისმიერი მოწყობილობიდან; Google ამ საქაღალდის გაზიარებას არ უშვებს, ამიტომ კოლეგები ერთმანეთის რუკებს ვერ ნახავენ.
  Sheet-ზე უფლება არ სჭირდება. Drive-ის ტოკენი ცალკეა (Sheet-ის ტოკენში Drive-ის უფლება არ ერევა და Apps Script-ს არ ეგზავნება).
- **დაკავშირების გარეშე** რუკა ინახება მხოლოდ ამ ბრაუზერში (localStorage).
- **გაზიარება** = რუკის ასლი ბმულის `#pm=…` ნაწილში (gzip). # ნაწილი სერვერზე არ იგზავნება, არსად ინახება; მიღებული მონაცემი მოწმდება.
  გრძელი ბმულის ნაცვლად შეიძლება „⤓ GeoJSON“ ფაილი: მიმღები მას რუკაზე ჩააგდებს (ფერებიც აღდგება).

Google Cloud-ში საჭიროა **Google Drive API** ჩართული (APIs & Services → Library). Code.gs ამისთვის არ იცვლება.
