# ხელშეკრულებების რუკა

ხელშეკრულებებით გადაცემული ქონების ინტერაქტიული რუკა: საკადასტრო კონტურები ფერდება ხელშეკრულების სტატუსის მიხედვით,
ჩანს NAPR-ის ორთოფოტოზე ან თანამგზავრულ ფენაზე, აქვს ფილტრები, ძებნა, თარიღის მიხედვით ისტორია, ნიშნები (დავალიანება, დარღვევა…)
და საჯარო View-ები ვადით.

## როგორ მუშაობს

- **მონაცემი** Google Sheet-შია (ხელშეკრულებები, სტატუსები, ქონებების ისტორია, ნიშნები, შეზღუდვები, გეომეტრიები).
- **გვერდი** (`index.html`, `js/backend.js`) GitHub Pages-ზეა. მომხმარებელი Google-ით შედის და Sheet-ს საკუთარი უფლებით კითხულობს:
  ვისაც Sheet არ აქვს გაზიარებული, ხელშეკრულებებს ვერ ნახავს, მხოლოდ სუფთა რუკას.
- **Apps Script** (`apps-script/Code.gs`, Sheet-ზე მიბმული, საჯარო Deploy „Me“ + „Anyone“) აწვდის საჯარო View-ებს
  Google ანგარიშის გარეშე მნახველს და ამოწმებს, აქვს თუ არა შესულს რედაქტირების უფლება.

## პარამეტრები

`js/backend.js` → `CONFIG`: `clientId` (Google Cloud OAuth Client ID), `spreadsheetId`, `publicApiUrl` (Apps Script-ის საჯარო `/exec` ბმული).
კოდში საიდუმლო არ არის: Client ID საჯაროა და მხოლოდ ამ საიტიდან მუშაობს.
